โครงงาน: ระบบเช็คชื่อเข้าเรียน (Attendance System)

[นายณัฐวุฒิ พุ่มประเสริฐ]

รหัสนักศึกษา: [6612247018]

กลุ่มเรียน/วิชาเอก: [วิศวกรรมคอมพิวเตอร์]

1

บทบาทและขอบเขตงานที่รับผิดชอบ

หน้าที่หลัก: พัฒนาระบบส่วนหน้าและเชื่อมต่อระบบปัญญาประดิษฐ์ (Frontend Developer & AI Integration Lead)

เป้าหมายผลลัพธ์ที่ได้รับมอบหมาย: รับหน้าที่สร้างและออกแบบส่วนติดต่อผู้ใช้งาน (UI) ใหม่ทั้งหมดให้สวยงาม ใช้งานง่าย และพัฒนากลไกการสแกนใบหน้า (Face Recognition) ให้มีความแม่นยำและรวดเร็วแบบเรียลไทม์ พร้อมปรับจูนโมเดลให้เข้ากับกล้องเว็บแคมทั่วไป

2

ผลการดำเนินงาน

ความสำเร็จของงาน: พัฒนางานที่รับผิดชอบลุล่วงไปแล้ว 70%

  • เตรียมส่วนหน้า (Frontend) รื้อและปรับโครงสร้างด้วย React และ Tailwind สำบูรณ์ 100%
  • สร้าง API สแกนใบหน้าและปรับจูนคะแนน Threshold เหลือ 0.35 สำเร็จ

หลักฐานการดำเนินงาน (ชิ้นงาน และผลการพัฒนา):

  • Source Code: GitHub (github.com/TanMakoto)
  • Deployment: โหมดนักพัฒนา (Localhost)
  • ผลการทดสอบ: ภาพสแกนใบหน้าผ่านและคืนค่าสำเร็จ

งานที่อยู่ระหว่างดำเนินการ (Pending):

  • Security: แสดงผล QR Code แบบ Dynamic สุ่มสร้างใหม่ทุก 1 นาที
  • Deployment: นำระบบ AI หลังบ้าน (Backend) ขึ้นระบบ Cloud
3

การใช้หลักการและเหตุผล

พิจารณาใช้ React (Vite) แทนวิธีเขียนหน้าจอแบบทั่วไป เนื่องจากทำงานแบบ Component-based ช่วยให้การประมวลผลกล้องภาพสดและการแสดงผลผู้เข้าเรียนพร้อมๆ กัน ทำได้รวดเร็วและไม่กระตุก

รวมถึงการเลือกใช้โมเดล AI อย่าง DeepFace (VGG-Face) ร่วมกับคณิตศาสตร์ Cosine Similarity เพราะเป็นโครงสร้างที่ได้รับมาตรฐานสากล มีความยืดหยุ่นสูง เหมาะกับแผนงานและต้านทานข้อผิดพลาดได้ดีเมื่อเผชิญภาพใบหน้าจำนวนมาก

* อ้างอิง: React Documentation (2026), CosFace Paper (2018)

4

การเชื่อมโยงงานกับภาพรวมของกลุ่ม

หน้าที่ Frontend และโมเดล AI เป็นหัวใจหลักในการเป็น "ตัวรับภาพและคัดกรองบุคคลหน้างาน" หากระบบสแกนฝั่งของผมมีข้อผิดพลาด ระบบทั้งกลุ่มจะไม่สามารถระบุตัวบุคคลผู้ใช้งานใดๆ ได้เลย ปัจจุบันส่วนนี้ได้พัฒนาเสร็จสิ้นเพื่อ ส่งมอบรหัสประจำตัวพร้อมใบหน้า ต่อให้เพื่อนฝ่าย Backend (API) นำไปเชื่อมต่อโครงร่างจัดการข้อมูลต่อไป

ข้อควรระวังสำหรับเพื่อน: ให้ระวังเรื่องการรับรหัสเข้าคิวซ้ำซ้อน เพราะขณะที่สแกนภาพอาจถูกยิงคำสั่ง (Request) ไปหา Backend หลายครั้งต่อเสี้ยววินาที (Concurrency) ควรทำระบบหน่วงเวลา (Debounce) หรือคัดกรองหน้าด่านเพื่อป้องกันข้อมูลเซฟซ้ำซ้อน

5

การวิเคราะห์ แก้ปัญหา และการเรียนรู้

ปัญหาที่พบ: เซิร์ฟเวอร์ Python หลังบ้านเริ่มระบบช้า (Lagging) รวมถึงสเปคกล้องเว็บแคมความละเอียดต่ำทำให้สแกนภาพล้มเหลว (Access Denied) ในช่วงแรก

การแก้ไขที่เรียนรู้: ได้ตรวจสอบและปรับการเขียนโค้ดตั้งค่าเปรียบเทียบใบหน้า (Threshold = 0.35) เพื่อชดเชยกล้องความละเอียดต่ำ และให้โหลดโมเดลเป็น Asynchronous ลดปัญหาคอขวดและเพิ่มประสิทธิภาพแถวหน้ากล้องให้สแกนได้เร็วขึ้น

6

แผนงานระยะถัดไป

หน้าที่ระยะถัดไป: นำเซิร์ฟเวอร์ AI หลังบ้าน (Python) ไปโฮสต์บนระบบคลาวด์ พ่วงตัวสร้าง Dynamic QR Code ทุกๆ 1 นาที และเข้าสู่ขั้นตอนประเมินทดสอบจริง (UAT) กับกล้องผู้เรียนหลายระดับ

อุปสรรคที่คาดการณ์: อาจเผชิญปัญหาเรื่องข้อจำกัดระบบ Cloud ฟรี รวมถึงความหน่วง (Latency) ของอินเทอร์เน็ตหน้างาน และสภาพแสงกล้องที่ไม่คงที่ในห้องเรียน
