# Standalone gesture application

Snapshot of the standalone webcam application from D:\Gesture-Recognition-master. This is separate from the web CCTV service in Gesture-Recognition-master/ and the shared Face/CCTV runtime in local-ai/.

Run with Python 3.11 and the existing OpenCV, MediaPipe, NumPy, pandas and scikit-learn environment: python "Gesture Recognition.py". A webcam and local gait training data (new_gait_dataset.csv) are required for the existing workflow. Face images, gait profiles, training data and movement logs are not included in this snapshot; supply your own local data.

For the web deployment, use local-ai/README.md and START-ALL.cmd instead.
